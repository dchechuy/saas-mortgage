# User Manual

## User Management

- Create users and assign them to roles.
- Control access by editing role permissions.
- Upload avatars from the top-right user menu or the user edit page.

## System Config

- Register LLM models and choose the default model.
- Maintain reusable attributes for future products.
- Store third-party integration credentials and endpoints.

## Help

- Keep quick start, manual, architecture, and dependency docs in markdown.
- Create release notes directly from the Help section.
